## Status Transitions Summary

### KAK Status Flow
```
DRAFT → MENUNGGU_APPROVAL → APPROVED → FINAL
                          → REJECTED → DRAFT (revision)
```

### Kontrak Status Flow
```
DRAFT → NEGOSIASI → MENUNGGU_TTD → AKTIF → SELESAI
                                        → DIPUTUS (terminated)
                                        → DIBATALKAN
```

### SPP → SPM → SP2D Flow
```
SPP:  DRAFT → DIAJUKAN → DIVERIFIKASI → APPROVED → TERBIT_SPM
                                      → REJECTED

SPM:  DRAFT → TERBIT → DIAJUKAN_SP2D → SELESAI

SP2D: DRAFT → TERBIT → DICAIRKAN → SELESAI
```

## Actors and Responsibilities

| Actor | Indonesian Term | Responsibilities |
|-------|-----------------|------------------|
| PPK | Pejabat Pembuat Komitmen | KAK, HPS approval, Kontrak, SPMK, BAST, SPP approval |
| Verifikator | Verifikator Keuangan | HPS preparation, SPP verification, Tax calculation, BAHP |
| Bendahara | Bendahara Pengeluaran | SPP preparation, SPM submission |
| Kuasa PA | Kuasa Pengguna Anggaran | SPM issuance and approval |
| Kuasa BUD | Kuasa Bendahara Umum Daerah | SP2D issuance and disbursement |
| Penyedia | Vendor/Contractor | Contract execution, Payment receipt |
